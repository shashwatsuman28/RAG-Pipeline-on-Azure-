# Roadmap

**Status**: Sequence proposal only; no calendar dates or delivery commitments.

1. **Documentation review**: approve constitution, scope, requirements, data policy, security boundaries, workload and open-question answers.
2. **Architecture decision closure**: decide document-permission authority, corpus, region, identity, models, search, processing, host, networking, cost, and conversation state. Re-run Spec Kit analysis.
3. **Implementation readiness**: approve project structure/runtime, API contracts, test datasets and quality gates, delivery ownership, and provisioning authorization.
4. **Future MVP**: if approved, build a bounded synthetic-corpus ingestion slice, then independently evaluated authorized retrieval/grounded response, then lifecycle/operations.
5. **Pilot/production decision**: only after measured capacity, security review, data-owner approval, recovery exercise, cost review, and operational ownership.

This roadmap is not approval for application implementation, cloud provisioning, or spending. Current next action is owner review of [open questions](open-questions.md).
